## 🐛 Troubleshooting

Most issues are easy to fix. Try these common solutions first:

### Problem: Application won't start in browser
- **Solution:** Make sure no other program is using port 8080. Close other applications and restart the service from Windows system tray icon.

### Problem: Bots stop running unexpectedly
- **Solution:** Check your internet connection. The platform needs stable connectivity to keep bots alive. Also verify that your computer hasn't gone to sleep - adjust power settings to "High Performance".

### Problem: "Connection refused" error
- **Solution:** Temporarily disable antivirus or firewall, then re-enable after adding an exception for `big-hosting-online.exe`. Windows Defender usually works fine without changes.

### Problem: Dashboard not loading after installation
- **Solution:** Open your browser's incognito/private mode. If it works, clear your browser cache (Ctrl+Shift+Delete in most browsers) and try again.

### Problem: Bot configuration changes not saving
- **Solution:** Ensure you click the "Save" button after making changes (not just the browser's back button). Also check that your browser allows local storage - it's required for saving settings.
